## 中文说明

AgentMeter {{VERSION}} macOS 版（构建号 {{BUILD}}）。

### 新增内容

- 新增 Kimi Code、GLM Coding Plan 和 MiniMax Token Plan 额度追踪，并按设备采集数据。
- 新增 Kimi API 余额，以及 OpenAI API 和 Anthropic API 的组织成本视图。
- 新增独立的服务商设置窗口，可在本机控制显示、排序、凭据和区域。

### 安全与隐私

- 手动添加的服务商凭据存储在本机 Keychain 中，使用不可同步的 ThisDeviceOnly 项目。
- OpenAI 和 Anthropic 管理员密钥受到保护，不会随跨源重定向发送。
- CloudKit、小组件和 Apple Watch 只会收到经过清理的额度或账单展示快照，绝不会收到服务商凭据。
- 读取现有 DeepSeek、OpenRouter 和 xAI 凭据时会自动强化其安全属性。
