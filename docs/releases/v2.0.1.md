AgentMeter 2.0.1 for macOS (build 23).

## What's new

- Fixed automatic recovery when an earlier unconfirmed resume attempt existed for the same Codex task.
- Fixed interrupted Codex tasks whose events were split across multiple rollout files.
- Kept single-shot safeguards that prevent duplicate resume messages while a request is active.

## Security and privacy

- Provider credentials remain local to the device and are never included in CloudKit records or diagnostics.
- CloudKit continues to use the existing production container and record schema; this update does not change synced fields.

## Download verification

- Universal macOS build for Apple Silicon and Intel.
- Developer ID signed, Apple-notarized, stapled, and Gatekeeper verified.

AgentMeter 2.0.1 macOS 版（构建号 23）。

### 新增内容

- 修复同一 Codex 任务存在较早的未确认恢复记录时，后续中断无法自动恢复的问题。
