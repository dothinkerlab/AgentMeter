AgentMeter 2.1 for macOS (build 24).

## What's new

- Added opt-in quota tracking for GitHub Copilot, Windsurf, JetBrains AI, and Zed.
- Configure Copilot with a GitHub token in Settings; other new providers use existing local sign-ins or quota caches.
- Added provider visibility controls and connection health reporting. Disabling a provider removes its synced snapshot.

## Security and privacy

- Provider credentials remain on your Mac and are never included in CloudKit records or diagnostics.
- Local provider databases and quota caches are read-only. Zed credentials are never refreshed or modified.
- CloudKit uses the existing Production container and record fields. New providers introduce additional provider and quota-window values.

## Download verification

- Universal macOS build for Apple Silicon and Intel.
- Developer ID signed, Apple-notarized, stapled, and Gatekeeper verified.
- SHA-256: `{{SHA256}}`
- Both DMG assets have the same SHA-256; `SHA256SUMS.txt` lists their checksums.

## 中文说明

AgentMeter 2.1 macOS 版（构建号 24）。

### 新增内容

- 新增可选的 GitHub Copilot、Windsurf、JetBrains AI 和 Zed 额度跟踪。

- CloudKit 沿用现有 Production 容器和记录字段；新增服务商会引入新的服务商与额度窗口枚举值。
