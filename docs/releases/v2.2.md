AgentMeter 2.2 for macOS (build 25).

## What's new

- Added TypeSafe API balance and usage monitoring with Chrome Auto and Manual cookie sources.
- Added Jev display-data synchronization through iCloud.
- Added opt-in Perplexity account credit tracking, three credit pools, and display-data synchronization through iCloud.
- Improved noninteractive browser and Manual credential reads so background collection does not prompt for Keychain access.

## Known limitations and release validation

- Perplexity requests may be blocked by a browser challenge. Failed or unavailable collection displays unknown or stale values, never an assumed zero balance.
- Perplexity fresh-credit comparison, Auto/Manual parity, Production schema deployment, and exact TestFlight/physical Watch validation remain pending. See `docs/PERPLEXITY_VALIDATION.md` and `docs/RELEASE_CHECKLIST.md`.
- Credentials stay on your Mac; only whitelisted display data is synchronized through iCloud.

## Download verification

- Universal macOS build for Apple Silicon and Intel.
- Developer ID signed, Apple-notarized, stapled, and Gatekeeper verified.
- SHA-256: `{{SHA256}}`
- Both DMGs are byte-identical; `SHA256SUMS.txt` lists their checksums.

## 中文说明

AgentMeter 2.2 macOS 版（构建号 25）。

### 新增内容

- 新增 TypeSafe API 余额及用量监控，支持 Chrome Auto 和 Manual Cookie 来源。
- 新增 Jev 显示数据 iCloud 同步。
- 新增可选的 Perplexity 账户积分跟踪、三个积分池及显示数据 iCloud 同步。

### 已知限制与发布验证

- Perplexity 请求可能遇到浏览器验证挑战。采集失败或不可用时显示未知或陈旧值，不将其推断为零余额。
- Perplexity 真实积分对照、Auto/Manual 一致性、Production schema 部署及准确 TestFlight／实体 Watch 验证仍待完成。详见 `docs/PERPLEXITY_VALIDATION.md` 和 `docs/RELEASE_CHECKLIST.md`。
- 凭据仅保留在 Mac，iCloud 仅同步白名单内的显示数据。

### 下载验证

- 通用 macOS 构建，支持 Apple 芯片和 Intel Mac。
- 使用 Developer ID 签名、通过 Apple 公证并完成装订和 Gatekeeper 验证。
- SHA-256：`{{SHA256}}`
- 两个 DMG 字节一致，校验和列于 `SHA256SUMS.txt`。
