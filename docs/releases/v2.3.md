AgentMeter 2.3 for macOS (build 26).

## What's new

- Fixed Codex automatic resume after quota interruptions when thread settings are updated. Verified settings changes preserve the failed turn; fresh task activity and duplicate submissions remain blocked.
- Added Volcengine Ark personal plan monitoring and settings.
- Improved Volcengine and MiniMax plan status, shared-pool handling, collection pause, and synchronization recovery.

## Validation and known limitations

- No CloudKit record schema changes in this release. Release artifacts use Production CloudKit.
- Volcengine real-account IAM/usage and Apple-client end-to-end checks remain pending.
- Real-account Perplexity Auto/Manual comparison and exact TestFlight/physical Watch end-to-end validation remain pending; fixture and unit-test results do not substitute for these checks.
- Credentials remain on your Mac; only whitelisted display data is synchronized through iCloud.

## Download verification

- Universal macOS build for Apple Silicon and Intel.
- Developer ID signed, Apple-notarized, stapled, and Gatekeeper verified.
- SHA-256: `{{SHA256}}`
- Both DMGs are byte-identical; `SHA256SUMS.txt` lists their checksums.
